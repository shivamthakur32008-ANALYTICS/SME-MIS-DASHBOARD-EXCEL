# 📊 SME MIS Dashboard - Excel

## Overview
This project is an interactive Management Information System (MIS) dashboard built in Microsoft Excel. It provides a clear view of key business metrics through KPI cards, Pivot Tables, Charts, and Slicers.

## Features
- KPI Cards
- Pivot Tables
- Interactive Charts
- Slicers for Filtering
- Business Performance Analysis
- Clean Dashboard Design

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas
